# S級ホール調査 公約チェッカー

結果報告シート（Excel）を読み込み、極・紫・赤・青・ハーフストロングの公約を満たしているか判定するWebツールです。
足りない公約には補填候補の台を出し、チェックを入れた台を補填したExcelを出力できます。
Excelの中身はブラウザの中だけで処理し、どこにも送信しません。

## 使い方
1. ページを開き、結果報告シートをドロップします。
2. 取材の種類（極・紫・赤・青）を確認します。ファイル名やシート名から自動で選ばれます。
3. 未達の公約の「補填候補」から、補填する台にチェックを入れます。
4. 「補填版Excelをダウンロード」を押します。どの書式を読み込んでも、公式の結果報告シート（極・紫・赤・青の4シート）の形で出力します。該当する取材のシートに全台データが入り、数えた公約の列に⭕️が付きます（補填した台の⭕️は水色）。

出力ファイル名は「日付_店舗名_取材.xlsx」（例：1010_PIA大森_赤.xlsx）です。日付はカレンダーで選び、店舗名は任意で入力します。どちらもファイルから初期値を入れます。

## Excelが無いとき：pisionから始める（ハーフストロングなど）
最初の画面の「pisionから始める」で、店舗と日付を選んで「読み込む」を押すと、その日の全台のデータを pision から読み込みます（APIキーの保存が先に必要です）。
次に「対象の台番号で色を付ける」に、メールの本文をそのまま貼り付けて「色を付ける」を押すと、書いてある台番号の台に色が付きます（⑤⑥として数えます）。
- 書き方の例：「・GOD：789-792/810/815-818」（「：」の後ろの台番号を読み、789-792 は 789〜792 の4台）
- 「ファイルから読む」（またはファイルを画面にドロップ）でも色を付けられます。色の付いた台のあるExcelはその台だけ、「台番」の列がある表はその列の台番号を読みます。
- 何回か分けて入れると、色が足されていきます。「色を全部消す」でやり直せます。

取材の種類は初めは「ハーフストロング」で、切り替えると極・紫・赤・青の判定もできます（次からは前に選んだ種類）。
ハーフストロングの公約は「2台以上設置の機種から、1/2（切り上げ）で⑤⑥の機種 ×10」です（`js/config.js` の halfStrong で変えられます）。
ハーフストロングのExcelは「ハーフストロング」（対象機種・台数・⑤⑥・台番の表）と「全台データ」の2シートで出力します。
アウト・セーフが無いので、取材の評価の出率は G数×3 をアウト、アウト＋差枚をセーフとして推定します。

## 取材の評価
対象（仕掛け台。補填した台も含み、同じ台は1回だけ）の平均出率＝セーフの合計÷アウトの合計 で ☆1〜3 を付けます（小数1桁で判定）。
非等価：☆3 110%以上・☆2 107%超〜110%未満・☆1 107%以下 ／ 等価：☆3 109%以上・☆2 106%超〜109%未満・☆1 106%以下。
極だけは、全体差枚がプラスでなければ ☆3 でも ☆2。等価／非等価は店ごとにブラウザが覚えます。基準は `js/config.js` の rating で変えられます。
「共有用にコピー」で、日付・店名・抽選人数・評価・総差枚・平均差枚・対象1台あたりの平均差枚と平均出率の文をコピーします。

## pision連携
「pision連携」を開き、pisionのAPIキーを入力して「保存」します（キーはそのブラウザの中だけに保存され、公開サイトや出力ファイルには入りません）。
店舗を選んで「pisionから取得」を押すと、台番号で照合して、シートで空欄のBB・RB・G数を埋め、機種名をpisionの正式名に置き換えます。
日付は「出力ファイル名」の日付を使います。「元に戻す」で取り消せます。判定のときの機種のまとめ方は変わりません。

## 台データオンライン（P-ARK）で補う
「台データオンライン（P-ARK）で補う」で店と日付を選んで「取得」を押します。台番号で照合して空欄のBB・RB・G数を埋め、機種名を置き換えます。
データ（台番号・機種名・BB・RB・ART・G数。差枚は無し）は、管理者のパソコン（C:\site7_tool）が台データオンラインを取得するたびに
koyaku_publish.py でこのリポジトリの `daidata/` に載せます（`daidata/index.json` に店と日付の一覧）。
ビューアで書き出した「日付_店名_台データオンライン.csv（.xlsx）」を「ファイルから読む」で読み込むこともできます。
pision と台データオンラインは、後から反映した方だけが使われます。

`daidata/` はパソコンから自動で更新するので、手元の koyaku-checker フォルダには置きません（古い一覧で上書きしないため）。

## 読み込める書式
.xlsx と .xls（Excel 97-2003形式）の両方を読めます。
- 公式テンプレ：台番号の左の列に公約ごとの⭕️
- ホールの出力データ：仕掛け台を色で塗り、右端の列に「全台」「並び」「1/2」のメモ
- ブロック形式：公約ごとのブロックに台を並べ、全台データは別のシート
- まとめシート形式：「まとめ」のシートに区分・台番号・機種・アウト・セーフ・差の一覧（左の一覧を使う）、全台データは別のシート（P-SIS の貼り付けなど）

## 設定の変更
- `js/config.js`：①の対象5機種、114.9%機種のしきい値、補填の色
- `data/payout6.js`：設定6機械割のデータ（DMMぱちタウンから取得）

画面の「設定」で、対象機種の選び直しや114.9%機種のチェックの付け外しもできます（114.9%機種の変更はブラウザに保存されます）。

## ファイル構成
```
index.html        画面
css/style.css     見た目
js/config.js      設定
js/parser.js      Excelの読み込み（書式の自動判別）
js/rules.js       公約の判定と補填候補
js/export.js      Excelの書き出し
js/pision.js      pision.io との連携（BB・RB・G数の補完、機種名の置き換え）
js/extdata.js     データファイル（台データオンラインの書き出しなど）の読み込み
js/rating.js      取材の評価（☆1〜3）と共有用の文
js/targets.js     テキスト・ファイルから対象の台番号を読む（pisionから始めたとき）
js/app.js         画面の動き
data/payout6.js   設定6機械割のデータ
template/report_template.xlsx  出力に使う結果報告シートのひな形（データは空）
```

ひな形を新しくしたいときは、記入済みの結果報告シートからデータを消して `template/report_template.xlsx` に置き換えてください。
更新したら `index.html` の `?v=` の番号も変えてください（ブラウザに古いファイルが残るのを防ぐため）。
